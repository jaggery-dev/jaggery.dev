Help make Jaggery

Jaggery is young and made by one person. The help that matters most is what one person can't do alone: hardware we don't have, apps we don't run, and fresh eyes on the first five minutes.

Ways to help

Try it and tell us what happened.
"I ran this on that, expected this, got that" is the most useful thing anyone can send, especially from a network or a machine we've never seen.
Run it on hardware we don't have.
An NVIDIA or AMD card, a Windows PC, a NAS, an Android phone, mesh Wi-Fi or a guest network. Many checks are a few commands and a comment.
Teach it an app.
Jaggery recognises self-hosted apps by asking a port a question and reading the answer. Adding one is a few lines and a test, and a good first change.
Fix the words.
Every message should say what's wrong and what to type. If something confused you, that's a bug.

Where to start

The code, the issues marked good first issue, help wanted and needs hardware, and the guide for contributors are on GitHub at jaggery-dev/jaggery. For anything bigger than a fix, open an issue first so we can agree the approach. Contributions are under Apache-2.0, signed off with git commit -s; there's no agreement to sign.

Using AI tools is fine, and much of Jaggery was written with them. A person answers for every pull request: you've read and run it, and you say which tools you used.

Questions, ideas and how it went in your house go in Discussions.

Not sure where you fit? Ask in Discussions, or write to hello@jaggery.dev and tell us what's in your house.
